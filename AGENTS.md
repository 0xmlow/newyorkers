# Read this first, whatever agent you are

This file is the entry point for **any** assistant working in this folder: Claude
Code, ChatGPT or Codex, Cursor, or something not invented yet. It is deliberately
short. Read it in full, then read only the one or two files below that your task
actually needs.

**Budget note.** MLow has been rate limited mid task before. Everything here is
ordered so you can be useful after about 200 lines of reading. Do not read the
whole folder. Do not `grep -r` the 22 GB of media.

---

## 1. The thing that will bite you first

There are **four copies of the website** in and around this folder and they all
differ. Only one of them is the source that reaches the internet.

| Path | What it is |
|---|---|
| **`NEW YORKERS SITE/`** | **The source of truth. Edit here. This repository.** |
| `GO LIVE PACKAGE/site/` | Build output. Regenerated by `build_deploy.py`. Never edit. |
| `GITHUB HANDOFF 2026-09-07/site/` | An older snapshot for handing to GitHub. Stale. |
| `~/.codex/.chatgpt-projects/g-p-<hash>/new-yorkers/` | A clone from a handoff bundle, where ChatGPT works. **Downstream.** |

The proof, if you want it: `NEW YORKERS SITE/_build/build_deploy.py` opens with
`SITE = os.path.join(ROOT, "NEW YORKERS SITE")` and writes into
`GO LIVE PACKAGE/site/`, which is what gets uploaded.

On 8 September 2026 a whole day of work was done in the Codex copy and could not
ship until it was ported by hand. **If you are ChatGPT or Codex, you are almost
certainly in the downstream copy. Say so out loud before you start editing, and
plan the port.**

## 2. House rules that gate all output

- **No em dashes, no en dashes, no arrows in prose.** Commas, full stops,
  colons. This is a brand rule and it applies to everything a human might read,
  including commit messages.
- **The artist is `MLow`.** Never his legal name in public copy.
- **Supply is never a total.** The collection is sold in named releases, each
  sized and closed before it opens, and no New Yorker is sold twice.
  `NEW YORKERS SITE/_build/releases.json` is the only source of truth for what
  has been promised. Do not invent a cap.
- **Nothing is signed.** Dates and prices are the artist's published intent until
  he says otherwise. Do not write "confirmed" or "final" anywhere.
- **Never deploy.** Building the package is fine. Uploading is MLow's, always.

## 3. Commands that matter

Run from `_build`:

```
./build_all.sh              # everything: hang assignment, museum bundle, audit, pages, package
python3 preflight.py        # read only. Must say "no problems"
python3 build_deploy.py     # writes GO LIVE PACKAGE/site. Does not upload
```

Museum only, from `_build/museum`:

```
node assign_hang.mjs        # every piece gets exactly one room. Rerun after data.js changes
node audit_rooms.mjs        # all 179 rooms headless in ~1s. Non zero exit means a work is unreachable
node audit_rooms.mjs --room=bowery   # one room, mount by mount, with its bounds and blocks
npm run check && npm run build       # typecheck and bundle
```

**Generated JavaScript must be checked before it ships.** `preflight.py` parses
every page's inline script. A collapsed newline once killed every button on a
page and looked healthy.

## 5. How to hand back

Leave three things behind:

1. **A commit per idea**, with the reasoning in the message.
2. **A note in the relevant handoff file** if you changed how something works.
3. **Say plainly what you did not verify.** This project has been burned by
   confident claims more than by bugs. "I could not measure this" is a useful
   sentence and it is always allowed.
