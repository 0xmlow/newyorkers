# THE PIGEONHOLE: notes for any agent

Read `README.md` (what it is, the twelve rooms, commands) and `BUILDER_BRIEF.md` (the engine API and house rules).

- Source: `src/`. Build output: `site/` (regenerated by `tools/build.py`; never edit it by hand).
- One room per file in `src/rooms/`. Room ids and order are in `src/main.js`.
- House rules: no em dashes, en dashes or arrows in any text; the artist is MLow; no real brand names or logos in the
  world (MLow twists only: NAZAR COLA, PIGEONCARD, EYE CRUNCH); every person has an Open Eye Flower for a head;
  original New Yorkers art is never tinted, covered or cropped.
- Verify every visual change with `tools/shot.py` and look at the PNGs. The disk on MLow's Mac is nearly always full:
  delete shots when done.
- On n3wyorkers.com the page is `/pigeonhole`, copied by `NEW YORKERS SITE/_build/build_galleries.py`. Deploying is
  MLow's call, through `NEW YORKERS SITE/_build/deploy.sh` only.
