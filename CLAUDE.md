# Builder handoff

Start with START-HERE.md. Preserve the commissioned humor, MLow palette, and 16 distinct visitor actions. This is a fictional NYC civic collage, not a reconstruction of an address. Do not call the browser result measured photorealism.

- `src/main.js`: bootstrap and curated collection allocation.
- `src/catalog.js`: deterministic thematic selection, stable art IDs; no duplicate works.
- `src/rooms.js`: the room registry, shared architectural helpers, and 16 builders.
- `src/engine.js`: pooled lights, texture cache, loaded GLB cache, neutral art, physical paper stickers, depth geometry, live portals and recursion, movement, collision, keyboard/touch, reduced motion, inspection.
- `src/sound.js`: synthesized procedural sound. No external audio.
- `public/assets/generated/`: four generated images. `plates/unlicensed.jpg` is the JPEG delivery copy; `depth/unlicensed.png` is the authored inverse-depth estimate.
- `public/catalog.json` and `collection.html`: generated by `node tools/catalog.mjs` from the same allocation code as runtime.
- `checks/validate.mjs`: real Three geometry factories with non-GPU loaders stubbed. `checks/browser-proof.js`: runtime doorway traversal, intended for the browser harness.
- `tools/shot.py`: optional macOS Chrome review harness; Python websocket-client is needed. It starts a temporary local server and temporary Chrome profile, then removes the temporary profile. It does not use the user's Chrome profile.
- `tools/package.py`: reproducible asset inventory and ZIP packaging. Excludes dependencies, credentials, caches and unrelated files.

One unit is a metre. Eye height 1.62. Rooms occupy frames 400m apart, preserving the existing engine. Bound all new portal passes and mobile recursion. `picture()` and `anamorph()` prepend `assets/`; direct texture loading does not. Static boxes can batch only if they have no registered click action. Animated objects and interaction targets remain separate. Persistent room caches are bounded by the fixed 16-room registry; disposal on whole app exit is by page unload, not an LRU room eviction scheme.

Never modify synced sources, original art/marks, or the upstream galleries. No deployment is authorized by this handoff. A receiving builder must obtain fresh deployment authorization and credentials. There is no assigned remote project ID for this new gallery.

Next work: see VALIDATION.md. Prioritize collision routes around animated props and real-phone memory/performance. Do not claim a threshold-only traversal proves an end-to-end furnished route. Keep production builds reproducible and update evidence after changes.
