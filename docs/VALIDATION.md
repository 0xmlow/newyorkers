# Evidence and practical limits

- Production Vite build passed with Three 0.185.1. The warnings about public data/fonts refer to assets copied unchanged by Vite; browser requests resolved successfully.
- CPU check constructs all 16 production room factories and validates finite geometry, 160 available work allocations, asset paths, all paired room destinations and the cyclic route. No GPU rendering is inferred from this check.
- Browser checks on local macOS Chrome with Metal rendered all departments. Full forward and reverse threshold tests passed for 32 transitions using the actual shared movement loop. The approach begins at the clear threshold; walking all the way around every furnished obstacle is not covered by that result.
- Browser asset error arrays were empty. No runtime exceptions or shader compilation errors were reported. Three's deprecated Clock emits a warning; it continues to function.
- `docs/shots/` contains actual browser renders, not generated concept previews. Some shots predate later civic fixtures and floor-material refinements; the final named shots reflect the later pass where available. Mobile review exposed title/navigation overlap; the responsive title width was corrected and recaptured.
- Measured full-frame draw counts include portal and post passes. The complete route pass recorded 167 (sky) to 858 (appeals), with recursive review at 504. The final refrigerator shortcut was added after that pass and was checked separately. These are not frame-rate measurements or a universal mobile performance claim. `docs/browser-results.json` records results when generated by the harness.
- Desktop/touch input and reduced-motion paths are implemented. The included mobile screenshot is an emulated viewport, not evidence from a physical phone. Real-device thermal behavior, extended touch use and long-session memory remain unverified.

## Prioritized continuation

1. Test complete furnished routes on desktop and a physical phone, especially the curved apartment installation and animated benches/carousel. Collision for the moving props is approximate; some props are intentionally non-solid.
2. The archive and recursive rooms exceed the usual 250-call review target. Consolidate shelf/label geometry and atlas repeated small text, then measure frame time on target devices. Keep artwork inspection neutral.
3. Asset resources cache across visits within the fixed 16-room world. If expanding the registry, add tested LRU eviction with late-load cancellation and shared texture reference counts.
4. Extend the terminal-still suite with close, oblique portal entry views and full click-to-ride sequences. Doorway walk transitions are verified; every scripted portal ride is not individually acceptance-tested.
5. Treat the generated skyline depth as shallow distant parallax. Avoid approaching or walking behind it; it is not fully reconstructed city geometry.

All fifteen new departments plus the intake hall are implemented. No proposed multiplayer, backend, tracking, monetization, or deployment is hidden in the build.
