# Collection expansion and bounded audits

Find the runnable source, room registry, generated bundle, artwork catalog, study copies and handoff copies. Verify paths mentioned in older READMEs exist before treating them as canonical. Record a build matrix; copied or alternate-renderer versions are not new architectural venues.

Search titles, area fields, descriptions and modeled subjects together. A renamed room, a neighboring view of the same building, or a new art page is not automatically a missing landmark. Keep stable existing IDs and append new IDs. Use a short primary-source ledger with verified signatures, estimated dimensions and explicit exhibition adaptations.

Reuse existing navigation, artwork loading, export and disposal contracts. Couple spawn, bounds, collision volumes, tour path and viewing targets to the architecture. Check registry generators accept the new definitions; compare runtime and generated counts. Update thumbnails and deep links with the new entries.

For an audit, run the existing type, construction, asset and production-build checks once per distinct runnable codebase. Report missing source modules or stale build scripts as findings. Recover a missing module from a compatible local study only after checking its interface; record provenance. A permissive stub can hide errors and cannot validate actual geometry or visuals. Construction failures must make a check fail rather than quietly passing on zero mounts.

Separate evidence: code compilation; finite real geometry and transforms; navigation-model diagnostics; browser-visible art and layout; measured renderer statistics; mobile input; and deployment. Advisory obstruction flags need visual confirmation. Record unresolved older findings rather than expanding an audit into an unlimited repair sweep. Do not claim every build was visually reviewed when only an inventory or sample was examined.

When the user requests token restraint, retain detailed per-room evidence in local JSON/CSV and return only totals, priority findings and links. Avoid repeated full source dumps, duplicate research, unnecessary agents and full reconstruction or rendering jobs. Save a clear next-work list so later fixes do not require rediscovery.
