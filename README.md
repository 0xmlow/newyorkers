# DEPARTMENT OF UNREAL ESTATE · NEW YORKERS by MLow

A fictional SoHo cast iron loft where reality is rent stabilized: a monumental everything bagel, a 900 square foot
studio that goes on forever, an anamorphic ring that closes from one spot on the floor, and a moire commute that
changes as you walk. 48 New Yorkers in four sets.

Walk it at https://n3wyorkers.com/unreal

`npm install`, `npm run dev` (port 5188), `npm run build` writes `site/`. The venue began in ChatGPT; the loft,
the studio tunnel and the ring are its code (`src/soho.ts`, `src/unreal.ts`), fixed and given a new controller here.
