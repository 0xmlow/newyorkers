# BIGGER ON THE INSIDE · NEW YORKERS by MLow

One Lower East Side block at night where every door opens onto a room far too big for its building: a bodega aisle
a mile deep, a walk-up where every floor is the fifth, an Ames room studio, a laundromat whose dryers look into the
other rooms, a subway car that rolls round you, and a roof where the city folds over the sky. Walk off either end of
the street and you walk back in at the other.

Walk it at https://n3wyorkers.com/inside

Start with `START-HERE.md`. `npm install`, `npm run dev` (port 5190), `npm run build` writes `site/`.
How every illusion works: `docs/HANDOFF.md`.
