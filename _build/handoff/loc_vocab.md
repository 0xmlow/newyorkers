# Place vocabulary for NEW YORKERS location metadata

Use exactly one of these forms for `place`:
- `key:<key>` for a named place below (landmark, venue, park, corridor, bridge, line, water, transit)
- `nb:<Neighborhood name>` for one of the basemap neighbourhoods listed at the end (exact spelling)
- `boro:Manhattan` | `boro:Brooklyn` | `boro:Queens` | `boro:Bronx` | `boro:Staten Island` when only the borough is knowable
- `null` when the prompt names nothing that fixes it to a borough or place
